# Lab Utilities

A script aimed to help with creating and managing laboratories in Linux and MacOS systems.

# Installation

To install, run the following command:

```sh
curl -fsSL https://raw.githubusercontent.com/xrMerida/labutil/main/install.sh | sh
```

# Features

- Focus on [Zed Editor](https://zed.dev/)
- Compatible with [Visual Studio](https://visualstudio.microsoft.com/)
- It uses:
  - [Bash](https://gnu.org/software/bash) the script itself
  - [CMake](https://cmake.org/) build system
  - [Ninja](https://ninja-build.org/) build system
  - [Clang](https://clang.llvm.org/) compiler
